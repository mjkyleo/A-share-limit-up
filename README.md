# 涨停预测工具 v2.5

VSCode 打开 `app.py` 按 **F5** 直接运行（或双击运行 `python app.py`）。

> 当前版本含 **2026-08-17 P0 统计根基加固**（统一涨停判定 / 指标模块 / shrinkage 动态权重 / 合成择时 / 精确成本）。详见「P0 优化：统计根基加固」节。

## 首次使用（一次性）

```cmd
pip install -r requirements.txt
```

## 日常使用

1. 把通达信导出的数据文件（收盘/自选池，xlsx 或 csv 均可）**放进程序目录下的 `data/` 文件夹**（首次运行自动创建）
2. 运行 `app.py`，程序自动扫描、识别、入库（界面「📁 数据文件」页可见每个文件被识别为什么类型、能不能用于预测）
3. 点「🚀 生成预测」→ 输出三张清单：
   - **明日涨停 TopN**（五策略 × 三路径交叉验证 × 可买性 × 风险惩罚）
   - **明日涨幅≥4%**（动量+量能+资金的低吸半路清单）
   - **跨日连板候选**（封单最强的连板种子）
4. 第二天收盘数据丢进文件夹，点「📊 运行回测」→ 自动配对昨天的预测，输出**分清单评分**（涨停满分/按涨幅分档/下跌扣分）、每个策略谁有效谁拖后腿，以及**自动调参建议**

## 尾盘选股（v2.1 新增）

交易快结束时（如 14:30）从通达信导一次盘中数据，命名格式为 **日期+批次号**（当天第几次导出）：

```
08-14-01.xlsx    当天第 1 次导出（如 10:30）
08-14-02.xlsx    当天第 2 次导出（如 14:30 尾盘）← 选股自动取批次号最大的
08-14-open.xlsx  开盘数据        08-14-close.xlsx  收盘数据
```

点顶部「🌆 尾盘选股」→ 自动取**最新日期的最新批次**，按 强势/资金/量能/位置 四因子（×可买性×风险）打分，输出尾盘买入清单（博次日溢价），清单自动入库、次日收盘后可同口径回测评分。

双轨候选：**涨停惯性**（封单稳的已涨停股，一字板会被可买性重罚）+ **强势未封**（涨 3%~9% 放量上攻股，博尾盘封板/次日冲高）。

## 回测评分体系（v2.1 新增）

每张清单有独立打分规则（`config.json` 的 `scoring` 节可调）：

| 清单 | 目标 | 满分 | 示例分档 |
|---|---|---|---|
| 涨停TopN | 次日涨停 | 涨停 100 | +6%→75，+4%→60，+2%→40，跌2%→-10，跌6%+→-80 |
| 涨幅4% | 次日涨≥4% | ≥4% 即 100 | +2%→40，跌2%→-10，跌6%+→-60 |
| 连板候选 | 再次涨停 | 连板 100 | +4%→50，跌2%→-20，跌6%+→-70（断板亏钱快，扣分最狠）|
| 尾盘选股 | 隔夜溢价≥2% | 涨停 100 | ≥2%→60，+4%→80，跌2%→-15 |
| 抄底清单 | 次日反弹 | 反弹 100 | +2%→60，+4%→80，跌不动→-10，续跌→-60 |
| 短线反转 | 次日反弹 | 反弹 100 | 同抄底口径，偏重下影线承接 |
| 防御低波 | 抗跌/微涨 | 稳健 100 | 小涨→100，震荡→40，大跌→-80 |
| 神经网络预测 | 次日上涨概率 | 同涨停口径 | 涨≥2%合格/≥5%满分，跌扣分（数据驱动，与五因子正交） |
| 自上而下 | 择时→板块→龙头 | 选股框架 | 次日涨≥2%合格（择时系数先定仓位，板块定方向，龙头定标的） |

「📊 回测评估」页可切换清单查看：单日明细（含每只得分）、单策略IC、策略IC滚动汇总、清单得分滚动、**💡 调参建议**（哪个策略反向就建议降权，累计≥3天给出具体建议权重，可一键应用）。

## 策略增强：正交风格 + 市场环境识别（v2.3 新增）

原版五个策略（封单/封板/锁仓/资金/股性）全部服务于「涨停接力 / 强者恒强」这一**单一风格**。当市场处于风险偏好下行（risk-off）时，这些因子会**同时失效**——表现为回测 TopN 收益全绿、所有因子 IC 为负。解决办法不是调参，而是给系统补上**对立 / 互补风格**与**天气系统**：

- **🔌 市场环境识别（market_regime）**：每天收盘后判断当前处于 risk-on / risk-off / 恐慌 / 震荡，给出建议主攻清单（动量 or 反转/防御）。基于 AKShare 免费接口的全市场涨跌家数、指数走势、成交额计算。
  > 注：v2.5 P0 起「总仓位」默认由 `synthetic_timing`（四指数+宽度合成）给出；`market_regime` 仍是风险偏好识别组件，二者互补。
- **🔌 抄底反弹（bottom_fishing，首个扩展）**：今日急跌但非下跌趋势、有承接、次日反弹概率高的股票。
- **🔌 短线反转（short_reversal）**：近 N 日跌幅大、今日收长下影（盘中承接强）、放量止跌、不在长期下跌通道——与涨停接力**正交**，risk-off 时主攻。
- **🔌 防御低波（defensive）**：低波动 + 估值合理 + 盈利稳定 + 中期趋势未坏——系统性下行时的"盾"。

> 六个扩展都走统一的「扩展框架」，新增一个能力只需往 `extensions/` 丢一个 Python 文件，无需改动核心代码（详见「技术文档.md」第 13 节）。

## 动态因子权重（v2.3 新增 · 解决"所有因子团灭" · P0 改为 shrinkage）

「💡 调参建议」页新增**动态权重计划表** + 开关（`config.json` 的 `dynamic_weights` 节可改）：

- **方法（P0 起 = `shrinkage`）**：每日 IC 先做 **EMA 平滑**（窗口 `ema_window`，默认 10）→ 单样本 t + **Bonferroni** 校正（α=`significance_alpha`，默认 0.05）判显著 → 不显著因子**收缩至地板 `floor`（默认 2%）**而非归零 → 权重 = (1−`shrinkage_lambda`)·max(EMA_IC,0) + 地板 再归一（`shrinkage_lambda` 默认 0.3）。
- **`auto_kill_negative`（P0 复用为显著性门槛开关）**：勾选 = 仅对"统计显著"的因子调权；不显著因子一律收缩至地板。它**不再字面"归零"**，避免有效因子被一刀切误杀。
- **⚠️ 回测时自动应用（`auto_apply`）**：勾选后每次回测自动把建议权重写入 `config.json` 并刷新参数页。

动作取值：`✅ 上调` / `⚠️ 维持(噪声收缩至地板)` / `❌ 不显著(收缩至地板)`。权重和恒为 100%；全部因子 IC 为负 → 空仓信号（全 0）。结合正交风格三件套（risk-off 时主攻），构成完整的多风格闭环。

## 神经网络预测（v2.4 新增 · 独立能力）

在「人工加权线性五因子」之外，单独接入一个**数据驱动的神经网络**，作为与之**正交**的预测视角。核心设计目标是"独立"：

- **数据自举**：首次训练从 **AKShare 历史日 K 线**（`stock_zh_a_hist`）为股票池构建样本；本地 `data/` 仅 2 天快照不足以训练，所以训练必须外援历史行情。特征全部来自**通用量价指标**（涨跌幅/波动率/量比/振幅位置/成交额 z-score/上涨天数比/均线动量等 12 维），**不依赖封流比等涨停细节字段**。
- **标签与映射**：标签为次日涨跌幅（回归）；再由 sigmoid 映射为「次日上涨概率%」与 0~100 的「NN评分」。
- **双后端**：默认 `sklearn` 的 `MLPRegressor`（多层感知机，快而稳）；可选 `torch`（PyTorch 深网，有 GPU 更佳）。模型与历史单独存 **`nn_model.db`**，**不污染主 `data.db`**。
- **接口独立**：在 GUI 里作为独立 Tab 出现，除「🚀 运行」外还有 **「🧠 训练/更新模型」** 按钮（后台线程，不卡 UI）；运行时也可自动训练（`auto_train`）。
- **与回测同口径**：其清单同样可被「📊 回测评估」按 `神经网络预测` 清单类型评分，由 IC / 动态权重决定"今天该信线性五因子还是神经网络"。

> 为什么独立：五因子是人工加权的线性组合，单一市场风格下容易团灭；神经网络从量价序列学非线性映射，是互补的、数据驱动的视角。两者并列，由回测客观裁决。

### 怎么用

1. 在 GUI 的「🔌 神经网络预测」Tab 点 **🧠 训练/更新模型**（首次较慢：拉股票池历史并训练，结果缓存到 `nn_model.db`，之后每日增量更新、推理秒级）；或勾选 `auto_train` 让首次「运行」时自动训练。
2. 点「🚀 运行」→ 输出 `神经网络预测` 清单（含 `NN预测涨幅%` / `上涨概率%` / `NN评分`），自动入库、次日收盘后可回测。
3. 在「📊 回测评估」下拉框选 `神经网络预测` 看其 IC 与得分，与五因子体系对比。

## 自上而下选股方法论（v2.5 新增 · 选股指导思想）

把「**用上证指数择时 → 行业板块找主线 → 主线龙头找个股**」这一选股原则，从理念落成
可量化、可回测的引擎 `core/topdown.py`，并封装为扩展 `extensions/topdown_pick.py`（与抄底/反转/防御/神经网络并列）。

三层、每层都可被排序/预测复用：

1. **择时（L1）**：取上证指数(sh000001)日线判断市道，输出「市道标签 + 仓位系数(0~1)」。
   取不到指数时回退到自选池「市场宽度」代理（上涨比例/涨幅中位数/涨停数），保证离线可用。
   **P0 起默认择时为 `synthetic_timing`**（见「P0 优化」节）：叠加上证 + 中证1000 + 创业板指 + 市场宽度四分量取均值仓位，比单看上证更稳。
2. **板块主线（L2）**：按 `所属行业` 聚合，板块强度 = 0.35·平均涨幅 + 0.25·平均20日
   + 0.20·涨停浓度 + 0.20·主力净量；强度 TopN 即「主线」——资金当下聚集的方向。
3. **龙头个股（L3）**：主线板块内按 动量 + 主力净量 + 流通市值(龙头偏大) + 封板质量 打分；
   非主线个股综合得分强降权（默认 70%），确保榜单由主线龙头主导。
4. **综合**：`综合得分 = (0.6·龙头评分 + 0.4·板块强度) · 择时系数 · (非主线降权)`——
   真正体现「择时定仓位、板块定方向、龙头定标的」。

> 与项目其他能力的边界：五因子/神经网络回答"哪只明天会涨停/涨"，自上而下回答
> "现在该不该出手、往哪个行业、选板块里哪只龙头"。前者管**标的胜率**，后者管**节奏与方向**，
> 两者正交、可在回测中并列裁决。

### 怎么用

1. GUI「🔌 自上而下选股」Tab 点「🚀 运行」→ 输出 `自上而下` 清单（含 综合得分/择时系数/市道/
   是否在主线/板块强度/龙头评分），自动入库。
2. 「📊 回测评估」下拉框选 `自上而下` 看其 IC 与得分（命中口径：次日涨≥2%）。
3. 把它的结论当成**总开关**：择时=进攻才重仓顺势；=防御则降到轻仓甚至空仓，无论个股多看好。

## P0 优化：统计根基加固（2026-08-17 缺陷体检后）

基于 2026-08-17 的「缺陷体检报告」，对回测统计根基与若干工程缺陷做了 8 项 P0 修复。这些改动**不改变使用方式**，但让回测结论更可信、涨停判定更准。核心改动：

- **统一涨停判定入口**：新增 `core/strategies.py` 的 `board_of(code)` 与 `is_limit_up(code, change_pct, th)`，作为全局唯一涨停判定；自动识别主板(9.5%) / 创业板·科创板 20cm(19.5%) / 30cm(29.5%) 阈值（来自 `config.json` 的 `thresholds.涨停判定涨幅_20cm` / `_30cm`），替换了原先散落的 `涨跌幅>=9.5` 硬编码，避免 20cm 个股被误判。
- **指标模块 `core/metrics.py`（新增）**：把统计计算收口为纯函数库，GUI 与回测共用同一套口径：
  - `per_trade_cost_pct`：双边成本 = 2×佣金 + 印花 + 2×滑点；20cm 用 `slippage_20cm`，主板用 `slippage_main`（**主板合计 0.35%、20cm 合计 0.55%**）。
  - `net_return_curve` / `benchmark_curve` / `rolling_net_curve`：等权组合**净值、年化夏普（√252）、最大回撤、胜率**（样本 <2 期时不计算夏普/回撤，避免噪声）。
  - `daily_ic_series` / `factor_significance`（单样本 t + **Bonferroni** 校正）/ `factor_correlation`（五因子 **Spearman** 相关矩阵）/ `incremental_ic`（正交化后的**增量 IC**，剥离其他因子后的边际贡献）。
- **动态权重改为 shrinkage**（详见「动态因子权重」节）：`auto_kill_negative` 现作为**显著性门槛开关**，不显著因子**收缩至地板(2%)** 而非归零，避免有效因子被一刀切误杀。
- **合成择时 `timing.method = synthetic`（默认开启）**：`core/topdown.py` 的 `synthetic_timing` 叠加四个分量取均值仓位系数——上证 sh000001 + 中证1000 000852 + 创业板指 399006 + 涨跌家数市场宽度（`breadth_timing` 兜底）。比单看上证更稳，避免单一指数噪声导致满仓/空仓误判。
- **成本模型 `backtest_cost`**：`backtest_one` 现按板块精确计成本（主板 0.35% / 20cm 0.55%），口径 `caliber` 默认 `close`（T日收盘→T+1收盘），缺开盘涨幅时自动降级 close 并提示。明细新增「口径收益% / 净收益% / 无法成交 / 双边成本% / 组合净值」等列；一字/秒板（涨停且封板分钟≤0.5）判为「无法成交」并从组合剔除。
- **净值/夏普/回撤放跨日层**：单日 n=1 不计算夏普与回撤（样本太小无意义），仅在累积 ≥2 个交易日后给出，结论更稳。
- **研究提示**：GUI 明日涨停 TopN 的「预估涨停概率%」列已正名为「排序分（非真实概率）」并附脚注——它只是五因子加权排序分，**不是真实概率**，请勿当概率解读。

> 测试：新增 `test_metrics.py` / `test_limitup.py`，与既有 `test_e2e.py` / `test_topdown.py` / `test_nn.py` / `test_smoke.py` 一并构成回归套件（详见上方目录结构）。

## 数据导入 vs 实时接口

| | 导入数据 `data/*.xlsx` | 实时接口 AKShare（免费） |
|---|---|---|
| 形态 | 通达信伪 xlsx（GBK 制表符文本，非真 Excel） | `stock_zh_a_spot_em` 全市场快照 + 市场活跃度 |
| 覆盖 | 精选子集（涨停/强势/自选，约 300 只） | 全市场 ~5000 只 |
| 独有字段 | 封板细节（封流比/封成比/首封时间/开板次数）+ 用户意图 | 全市场广度、指数走势、市场环境 |
| 用途 | 涨停/连板接力**必需**（接口拿不到封板字段） | 全市场扫描 + 市场环境识别**必需** |

> 结论：两者**互补而非替代**。导入数据是最不可替代的"深度数据源"（封板 + 用户意图），接口补的是"全市场广度 + 天气温度计"。每个扩展在 `config.json` 的 `datasource` 字段声明走 `local` 还是 `akshare`，运行时自动切换。

## 文件命名格式（建议）与识别规则

**建议命名**（日期格式 `YYYY-MM-DD` 或 `MM-DD` 均可）：
```
2026-08-13-close.xlsx   收盘数据（每天必有）
2026-08-13-open.xlsx    开盘/竞价数据（可选）
08-14-01.xlsx           盘中第1次导出（尾盘选股用）
2026-08-13-自选.xlsx    股票池快照
```

**开盘/收盘的三层自动判定**（文件名没写关键词也能认）：
1. **文件名关键词**：`close/收盘/盘后` → 收盘；`open/开盘/竞价/早盘` → 开盘；**日期+批次号** → 盘中批次
2. **内容特征兜底**：开盘快照里 `涨幅≈开盘涨幅` 且 `全天换手≈竞价换手`（9:30 前只有竞价一笔成交），程序自动识别
3. **修改时间兜底**：导出时间 <12:00 倾向开盘，≥14:00 倾向收盘

每个文件的判定依据会显示在界面「📁 数据文件」页（如"时刻判定:内容特征"）。

| 文件名含 | 识别为 | 用途 |
|---|---|---|
| `close` / `收盘` | 收盘快照 | 预测+回测验证 |
| `open` / `开盘` / `竞价` | 开盘快照 | 早盘选股补充 |
| `08-14-01`（日期+序号） | 盘中批次快照 | 尾盘选股（取当天最大批次） |
| `自选` | 股票池 | 预测 |
| `排名结果` / `final_rank` | 历史预测 | 自动回测对照 |

数据日期自动从列名后缀 `[20260813]` 或文件名 `08-14` 提取；表头**顺序任意**、缺列自动降级。

> 数据保护规则：同一天既有盘中/开盘快照又有收盘文件时，回测基准库**只保留收盘数据**——盘中与开盘数据不会覆盖收盘记录。

## 交易日规则

- 周一~周五交易，周末（含调休工作日）闭市，法定节假日闭市
- 预测目标日自动取**下一交易日**（如周五的数据 → 预测周一）
- 节假日表有变动时，在 `config.json` 的 `extra_holidays` 里加日期即可

## 策略说明

v2 权重经 08-13 实盘回测校准：封单强度 0.40（ρ=+0.598 显著）、封板质量 0.25、锁仓度 0.15、股性结构 0.15、资金 0.05（当日呈弱反向，降权观察中）。随着回测天数积累，「📊 回测评估 → 💡 调参建议」会基于滚动 IC 自动指出哪个策略拖后腿、给出具体建议权重（≥3 天样本），可一键应用到「⚙️ 策略参数」。

**重要认知（v2.3）**：当回测显示所有因子 IC 同时为负，是市场风格切换（risk-off）信号，而非参数错误。此时应通过「动态因子权重」把失效因子归零，并切到抄底/反转/防御三件套（这些清单在「回测评估」下拉框中同样可选，同口径评分）。建议每天坚持入库，累计 ≥20 个交易日再下结论。
